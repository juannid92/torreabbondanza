## Content Production Workflow (Per Ogni Piece)

### Blog Post Workflow
1. **Brief** (Owner, 1h): keyword target, search intent, H2/H3 outline, CTA placement, internal links planned
2. **Draft** (Owner/AI-assisted, 3-4h): prima stesura con struttura completa, immagini placeholder
3. **SEO Review** (Dev/AI, 1h): meta title (<60 chars), meta description (<155 chars), alt text, internal links, readability
4. **Implementation** (Dev, 2-3h): TanStack Router route, MDX/React component, schema BlogPosting, responsive images
5. **Publish + Distribute** (Dev, 1h): deploy, GSC URL inspection, social share, GBP post reference
6. **Monitor** (Dev, 30 days later): GSC impressions/clicks, ranking position, adjust if underperforming

### Service Page Workflow
1. **Keyword Research** (Dev, 1h): primary keyword + 3-5 secondary, SERP analysis top 3 results
2. **Competitor Content Analysis** (Dev, 1h): word count, H2/H3 structure, schema types, CTAs used
3. **Content Brief** (Owner+Dev, 1h): outline, unique angles, E-E-A-T signals to include, CTA strategy
4. **Design Integration** (Dev, 2-3h): parallax, GSAP animations, responsive layout, brand consistency
5. **Schema Implementation** (Dev, 1h): JSON-LD specifico per page type, Rich Results Test validation
6. **Internal Linking** (Dev, 30min): 3-5 contextual links from related pages + footer nav update
7. **QA + Publish** (Dev+Owner, 1h): mobile test, accessibility check, schema validation, deploy
