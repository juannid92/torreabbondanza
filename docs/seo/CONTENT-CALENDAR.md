## Content Production Workflow

### Per Ogni Blog Post
1. **Brief** (Owner): keyword target, intent, punti chiave, CTA
2. **Draft** (Owner/AI assist): 1a stesura con struttura H2/H3
3. **SEO Review** (Dev/AI): meta title, description, internal links, alt text
4. **Pubblicazione** (Dev): route TanStack Router + schema BlogPosting
5. **Distribuzione**: social share + GBP post + newsletter (se attiva)
6. **Monitoraggio**: GSC impressions/clicks dopo 30 giorni

### Per Ogni Pagina Servizio
1. **Keyword research**: primary + 3-5 secondary keywords
2. **Competitor analysis**: top 3 SERP results content structure
3. **Content brief**: word count, H2/H3 structure, CTA placement
4. **Design integration**: immagini, parallax, GSAP animations coerenti
5. **Schema markup**: JSON-LD specifico per page type
6. **Internal linking**: 3-5 link da pagine correlate + footer nav
